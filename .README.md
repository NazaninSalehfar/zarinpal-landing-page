# ZarinPal Landing Page

A responsive recreation of the ZarinPal website interface, developed as a frontend practice project using HTML, CSS, and JavaScript.

## About the Project

This project was created to practice frontend development and recreate the layout and visual design of the ZarinPal website.

## Built With

- HTML5
- CSS3
- JavaScript

## Features

- Responsive layout for desktop and mobile screens
- Structured HTML markup
- Custom CSS styling
- JavaScript interactions
